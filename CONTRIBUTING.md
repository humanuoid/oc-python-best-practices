# Contribuer

Ce dépôt est un espace d'apprentissage. Les contributions se font dans le cadre des exercices du cours.

## Conventions

- Identifiants en anglais, commentaires et messages utilisateur en français.
- PEP 8 ; stdlib seule.
- Signature longue : un paramètre par ligne, parenthèse fermante au niveau du `def`.
- Commits en conventional commits (`type: description`), en français.

## Workflow

1. Créer une branche par exercice ou correction.
2. Vérifier le code avec `uv run` avant de pousser.
3. Ouvrir une pull request pour revue.
